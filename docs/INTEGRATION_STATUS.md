# AdPilot AI — Integration & Component Status Matrix

This report classifies every AdPilot AI subsystem and external integration using only observed verification evidence from repository inspection, automated tests, live host checks, and 3-service E2E browser execution.

Allowed classifications:
- `VERIFIED LIVE` — Exercised successfully against live external endpoints/services during this audit.
- `VERIFIED LOCALLY` — Verified locally against running local services/builds/unit & integration suites with zero failures.
- `MOCKED / SIMULATED` — Core logic/contracts tested using mocked providers, stubs, or synthetic fixtures.
- `BLOCKED BY CREDENTIALS` — Implemented and unit-tested, but live external execution requires credentials, API tier entitlement, or OAuth tokens absent in this environment.
- `NOT IMPLEMENTED` — Referenced in dependencies/metadata but not implemented in active runtime code.
- `FAILED` — Broken in current verification run.
